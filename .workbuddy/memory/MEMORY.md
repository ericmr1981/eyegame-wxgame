## VisionKit 链路（唯一可用路径）
`wx.createCamera({devicePosition:'front'})` → 等 3s 前置生效 → `wx.createWorker(...,{useExperimentalWorker:true})`
+ `listenFrameChange(worker)` → worker 内 `getCameraFrameData()` 取裸 ArrayBuffer
→ 主线程 `createVKSession({track:{face:{mode:2}}})` + `detectFace({frameBuffer,w:288,h:512,sourceType:0})`
→ 结果**只从 `updateAnchors` 事件**。`anchor.angle`=(pitch,yaw,roll) **弧度**；
帧 RGBA 288×512=589824B（不带宽高）；相机**默认后置**须等 1s。
- ✅ **Camera 可隐藏**：接受 x/y/width/height → 丢屏幕外 `-4,-4,2,2` 无预览
- 无 `createOffscreenCanvas` · `open3d` 需微信 ≥8.1.0（当前 8.0.78 不可用）
- iOS 主线程 `Camera.onCameraFrame` 拿不到帧 · 冒烟：主 canvas = 屏幕逻辑像素

## 玩法 · 纵轴隧道
- 纵轴卷轴：飞船 y=0.78H，世界自上方涌来 → **必须竖屏**；Canvas 2D + 伪 3D（尺寸∝1/z）
- ★ **速度感与可玩性解耦**：机制速度有红线，视觉速度自由拉高
- 穿越隧道：须保持管内、贴中心线；`|wx−cx| > hw−SHIP_HW` 扣血；蹭壁软推回 45% + 1200ms 无敌
  · 红线：中心线斜率 ≤ `TUN_SLOPE_MAX=0.28`
  · 渲染：对数采样 21 档 → 左右管壁折线 + 横向肋条（肋条渐亮渐粗 = 速度感主力）
- **控制**：**歪头 roll → 横移**，约定 `轴值>0⟺右移`，`ROLL_SIGN`/`YAW_SIGN` 一处收口
  · `ROLL_SIGN = +1`（头向右肩歪 → 飞船右移）
  · roll 滤波比 yaw 厚：EMA τ**0.18s**、外推 **0.32**（yaw 3°/0.09/0.55）
  · ★ **「幅度」档**（底部第 2 按钮，落盘 `bd_range`）：只改 dead+full，`ROLL_XRANGE=1.15`/`ROLL_VMAX=5.5` 三档恒定
    值：紧凑 3°/20° · **标准 3.5°/25°(默认)** · 舒展 4.2°/36°；颈椎阈值 7.5/9.5/12.3°
  · **降敏感度的正确姿势 = 抬高满量程，不是砍增益**（砍增益只让飞船变肉）。钟摆已收敛，勿再拉默认档
  · 四档控制（「控制」按钮循环）：歪头·位置(默认)/位置反/歪头·速度/转头·位置
  · **pitch→Boost（≤3s + 冷却 4s）** · 丢脸>400ms 输入回中 · 零点静息带慢校正(死区×1.3)
- 降级：`visionkit → gyro → touch`（摄像头 6s 未就绪自动降级）

## 核心机制（当前 v7）
**能量块（P0）**：块横向 = `中心线cx + off×半宽hw`，**只有 off 是额外的颈部横摆量**。
生成单位是 **pattern（串）**（sweep/wave/zig/edge/near），逼玩家**连续跟随**。
- `ROOM_SCORE`（居中/秒）14→**5**，让块成主收益（块≈1350 vs 居中≈300）
- 节拍按时间不按距离：`ORB_GAP_SEC=0.52s`；★ **`gapScale`：跨度越大节拍越长**（可玩性红线，同 TUN_SLOPE_MAX 形式）
- 碰撞用**跨越飞船平面**（`pz>0 && dz<=0`）而非窗口判定（高速一帧走 0.46 单位，窗口式必漏）
- 连击：**错过不清零，只有蹭壁清零**（放弃收益换安全不该被惩罚）；封顶 `COMBO_CAP=9`
- `ORB_OFF_MIN=0.28`（靠中两档占 45%）；串内 `jitter` 抖动
- ★ **块可达性**：块位置按"这一侧剩余空间"自适应收敛，否则中线上偏时贴边块永远吃不到
- `refillOrbs` 生成上限须**贴着视野**（`scroll+SHIP_Z+ORB_VIEW`），否则新串生成在视野外被裁剪永久删除 → 空窗

**居中连乘（v7）**：`cent ≥ MULT_HOLD_CENT(0.62)` 攒倍率 `1→MULT_MAX(5)`，`MULT_RAMP_SEC(6)` 秒满；
脱离 `> MULT_GRACE_SEC(0.7)` 清零；**撞墙立刻清零**。**倍率 × 一切得分** → 贴中线=投资、够块=兑现。
- ★★ **宽限是必需的**：块 `off≥0.28`，一离开就清零 ⇒ 吃任何块都破倍率 ⇒ 没人敢够块 ⇒ P0 废
  → 0.7s 造出取舍表：**单块短冲不破倍率（甜点）/ 4 块长串必破（高风险大餐）**
- 可视化：飞船外圈光球（半径/亮度 ∝ 倍率）· 升档脉冲 · 破倍率红环 + 下滑音 · HUD `倍率 ×3.2`
- ⚠️ **平衡窄**：单块高倍 450 vs 破倍率重建 6 秒损失 ~230 → 净 +220。真机后大概率调 `ORB_SCORE`/`MULT_RAMP_SEC`
- ★ 测试教训：`render()` 内部会跑 `updateWorld→updateMult` **重算倍率** → 断言前把状态钉在**稳定支**

**音效**：`wx.createWebAudioContext` 零素材合成（`tone(freq,dur,type,gain,slideTo)`）。
★ iOS 硬规则 = AudioContext 必须在**用户手势同步栈**内激活：`onTouchStart` 首行 `unlockAudio()`
→ 无条件 `resume()`（不判 `state`）+ 播 0.02s 近无声激活音；`wx.setInnerAudioOption({obeyMuteSwitch:false})`。
**离线冒烟测不了，只能真机验证**。
