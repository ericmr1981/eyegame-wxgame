## 关键诊断结论（2026-10-04 17:50）
**MediaPipe vision_bundle 在微信小游戏环境结构性不兼容**：
1. 浏览器假设：importScripts(loader.js) 同步执行 → var ModuleFactory 进 window → Module({}) 可用
2. 小游戏实际：eval/importScripts/Function 都被禁（ES module 严格模式）→ ModuleFactory 永远进不了 globalThis
3. Worker 方案：模拟器里 wx.createWorker 不实际启动 worker.js
4. ES module export：模拟器下 import 后所有 export 都是 undefined

**结论**：POC 不可行（不是方法错了，是平台架构性约束）。需要换方案：陀螺仪 + 简化头部控制，或放弃头部控制改陀螺仪。

## 摄像头路线（v6-v9b）也堵死
- **小游戏真机 Camera API 是空壳**（v9b 验证）：
  - `wx.createCamera` 是 function ✓
  - 创建的 Camera 对象 `Object.keys(getPrototypeOf(cam))` 是空数组
  - `Camera.onCameraFrame`、`start()`、`stop()` 等方法**不存在**
  - **小游戏 iPhone 真机上拿不到摄像头帧** — 平台层限制，不是个例 bug
  - **结论**：小游戏不能做摄像头帧的头部检测，**必须放弃"原生摄像头"路线**
