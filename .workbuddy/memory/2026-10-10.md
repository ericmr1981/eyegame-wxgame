产出 `脖动圈_核心元素_金龟子飞行姿态_v1_2026-10-10.md` + 内联三态俯视图（闭合/常态飞行/Boost）。

### ★ 先分清"两层翅膀"（画错的根源）
- **鞘翅 elytra**：外层硬壳，不透明有金属光泽；飞行时**向上张开**当稳定面 → 实心绿 `#7FA83E`
- **膜翅 后翅**：内层，**透明**薄膜；才是真正的动力，**高速扇动**，平时折叠藏在鞘翅下 → 半透明冷白 `#D8FFE8`
- ★ **这是本主题最大的视觉红利**：甲虫飞行天然自带"壳打开 + 透明翅扇动"的"在飞"表达，**不需要速度线去假装**。其他飞行游戏的飞船只能靠拖尾装。

### 三态参数（俯视/背面视角）
| | 闭合(仅参考) | **常态飞行** | **Boost** |
|---|---|---|---|
| 鞘翅开角 | 0° | **±14°** | **±58°** |
| 膜翅 | 不可见 | 0.8×鞘翅长，opacity .22，轻扇 | 1.2×，opacity .26，**残影×3** |
| 腹部 | 全遮 | 微露 | 明显 + 3 条节纹 `#3A4E1C` |
| 过渡 | — | 收回 350ms ease-in-out | 展开 **180ms ease-out** |
★ **为什么常态"微张"不"全张"**：① 给 Boost 留跃迁余量（14°→58° 差异巨大才有反馈）② 全张轮廓宽 1.6×，常态太张扬抢戏 ③ 残影成本不该常态化
→ 所以"飞行时展开"这个要求**已满足**（常态就张开，不是滑翔的方块），Boost 是"张得更开、扇得更急"。

### ★★ 红线：翅膀**不参与碰撞**（必须写死在代码注释里）
`SHIP_HW: 0.10` 是**玩法参数不是美术参数**。翅膀展开后视觉轮廓约 2.0→3.2 宽，但**判定盒必须不变**。
理由：碰撞盒直接决定难度（与 `TUN_HW_MIN 0.42`/`X_LIMIT 1.25` 配套调过）；若翅膀参与判定，**Boost 会变成惩罚**（张开=更易撞壁），违背设计意图。
→ 做法：翅膀只在渲染层画，判定只读 `g.wx`，与姿态**零关联**。

### ★ 实现坑（两个）
1. **旋转锚点在"肩部"不是中心**：鞘翅绕**鞘翅基部铰链**转（左鞘翅顺时针、右鞘翅逆时针）。2D 里用"绕肩部旋转=开壳"作**视觉约定**（真动作是三维的，俯视无法直接呈现），**不必纠结物理精确**。
2. ★★ **膜翅"急扇"不能用真实频率画**：真甲虫振翅 20~40Hz，60fps 每帧仅 16.7ms → 每帧不到半周期 ⇒ 画面不是"高速振动"而是**采样混叠的闪烁**。
   **正解**：常态用低频真实摆动(3~4Hz)；Boost **不逐帧变角度**，改**同时画 3 个不同角度的低透明度膜翅叠加**(.26/.12/.08) —— 用**残影暗示**高频，且**不用 `filter:blur`**，性能安全。
3. 性能：常态 ~4 path / Boost ~8 path（原三角形 1 path）。可接受，但**不许因此放宽其他绘制预算**。
4. 飞行时六足**收拢贴体**（真甲虫姿态），只需 6 条短线段 → "更写实"和"更省性能"方向一致。
5. 轮廓光：鞘翅**有**（张开后跟着转）；膜翅**不要**（半透明+轮廓光会变脏）。旋转**不改光源方向**（仍上方偏左 15°），否则像"开了第二盏灯"。
6. 过渡"快速展开(180ms ease-out)、缓慢收回(350ms ease-in-out)" = 生物本能节奏，反过来会机械。
