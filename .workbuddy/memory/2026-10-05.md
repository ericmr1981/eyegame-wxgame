- 官方错误原文：`please go to mp open official popup or use wx.onNeedPrivacyAuthorization to announce your privacy`

### 两条解法
- **A 后台开通「隐私授权弹窗」**（POC 推荐，零代码，进入自动弹官方弹窗）——该组件一经启用不可关闭

- 小游戏未注册 onNeedPrivacyAuthorization 时，默认用平台统一隐私弹窗
### 两个坑
- 开发版/体验版可能不生效：隐私权限需**重新发布**才在正式版生效 → 后台刚配完预览版仍可能 1026，别反复改代码

### 查实的官方接口（minigame + miniprogram 文档）

### 尺寸反推思路（v6 核心）
`px = byteLength / 4`（每像素 4 字节 RGBA）→ 589824/4 = **147456 px** → 枚举因数对（≥64、≤2048、8 的倍数、长宽比 0.25~4）
→ 按接近 9:16 排序 → `288x512`(首) / `256x576` / `192x768` / `384x384` / 512x288 … 共 7 组
→ **逐帧轮流喂 detectFace，哪组出人脸就锁定哪组**
